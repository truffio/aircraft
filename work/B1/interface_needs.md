# B1 — Interface needs

What the L1 architecture (`specs/FUNCTIONAL_ANALYSIS.md` §3, §5) needs from the ICDs (task I1) and from the L2 agents (C1 to C8). Interface IDs I-nn refer to FUNCTIONAL_ANALYSIS §3.2.

**Refreshed at the G1 rework (2026-11-04, G1-F10).** The mode catalogue is D56: there is no VOR, no flight path angle, no track hold, no separate position-hold mode and no speed mode. The flight control panel (FCP, task C8) is its own subsystem (D55). Material that the first B1 draft wrote against D3, D11 to D14 or a seven-subsystem architecture is struck through below and marked **Superseded**; it is kept only as a record and is not an input to any L2 agent.
