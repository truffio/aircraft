# C4 — Glossary proposals (FC)

Proposals for `specs/GLOSSARY.md` from task C4. New terms need no change request; changed definitions of Fixed terms do (D43): C4 proposes **CR-C4-04** for the refinements in §2 (`work/C4/issues.md`).

## 1. New terms

| Term | Definition | Source |
| --- | --- | --- |
| Axis (of regulation) | One of the six degrees of freedom that *flight control* regulates separately: the *north*, *east* and *vertical* axes of the *vehicle-carried local frame* V for translation (the vertical axis in altitude and vertical speed, positive up, CV-430, CV-490) and the *roll*, *pitch* and *heading* axes for rotation. | DD-290; L2-AER-FC-010 |
| Reference value, reference rate, reference acceleration | The three parts of an *axis reference*: the value of the regulated quantity (a position, an altitude, an angle), its rate of change (a velocity, a vertical speed, a *body rate*) and the rate of change of that rate. The rate and the acceleration are feed-forward when the value is regulated, and the acceleration when the rate is regulated. The *reference acceleration* of the translational axes is the vector of the three translational accelerations, resolved in frame V. | DD-290; L2-AER-FC-020, -140 |
| Regulated quantity | For a translational *axis*, what the axis reference asks *flight control* to regulate: the *position* (the reference value) or the *velocity* (the reference rate). Each translational axis states it with its reference. A rotational axis always regulates its angle. | DD-290 |
| Off value | The single value that *autoflight* sends to *flight control* in place of the six *axis references* on the ground. While *flight control* receives it, it sets the *effector activation state* off and each *effector command* to zero. It carries no mode information. | D69; L1-AER-420; L2-AER-FC-190 |
| Reference step | A change of an *axis reference* between two consecutive *control frames* that the reference acceleration of the first frame does not explain by more than the *tracking tolerance* of the axis; or a change of the *regulated quantity* of the axis; or the first control frame whose axis references are not the *off value*. A ramp that *autoflight* shapes within its acceleration limit is not a step. | L3-AER-FC (introduction) |
| Tracking tolerance | The largest departure of the regulated quantity of an *axis* from its reference that a flight control requirement allows, by axis and regulated quantity: `[P-FC-010]`, `[P-FC-030]` (position), `[P-FC-040]`, `[P-FC-050]` (velocity), `[P-FC-070]`, `[P-FC-080]` (heading and heading rate), `[P-AF-180]` (pitch and roll). It applies at the *control frames* that do not lie within the *settling time* of a *reference step*. | L2-AER-FC-100, -110 |
| Settling time (flight control) | The time from a *reference step* in which an *axis* has to be within its *tracking tolerance* again: `[P-FC-060]` for the translational axes and `[P-FC-090]` for the rotational axes. Not the settling time `[P-AF-190]` of autoflight captures. | L3-AER-FC-TR-060, -RO-050 |
| Acceleration demand | The vehicle acceleration that the *translational regulation* asks for along each translational *axis* (the vector in frame V). It is limited to `[P-SYS-440]` and converted to the *axis demand* (a force along each body axis) with the *vehicle mass* of the frame. | DD-300, -04; L3-AER-FC-TR-070 |
| Translational regulation (TR), rotational regulation (RO), control allocation (AL) | The three sub-functions of *flight control*. TR gives the force demands from the three translational *axis references*; RO gives the moment demands from the three rotational ones; AL gives the *effector commands* from the six *axis demands*. | L3-AER-FC |
| Limited axis demand | An *axis demand* that *flight control* replaces by a smaller one, because it lies outside the *authority box* or because the *acceleration demand* exceeds `[P-SYS-440]`. Limiting is nominal behaviour, not a failure, and it changes no state of the Aeronef other than the commands (N-260). | L2-AER-FC-130, -170 |
| Descent call | The state in which the reference rate of the vertical *axis* is below zero. Flight control caps the upward control force while the gear is extended and a descent is called (L2-AER-FC-210). | DD-330 |

## 2. Refined definitions (CR-C4-04)

| Term | Current | Proposed |
| --- | --- | --- |
| Axis reference | "The value toward which *flight control* regulates one *degree of freedom*, produced by *autoflight*. Which quantity each reference is (velocity, position, rate, attitude) is set at L2 (C4, C5). The only data autoflight passes to flight control (D15). On the ground it takes an off value, with which *flight control* commands zero effector output (*effectors off*, D69); the off value carries no mode information." | "The reference of one *axis*, produced by *autoflight*: a *reference value*, a *reference rate* and a *reference acceleration*, and for a translational axis its *regulated quantity* (DD-290). The translational axes are those of frame V. The six axis references, or the *off value* in their place, are the only data autoflight passes to flight control (D15, ICD-FC-AF)." Reason: C4 sets the quantity and the frame, which the current text leaves open. |
| Axis demand | "A force along, or a moment about, one body axis that the regulation function of *flight control* asks the allocation function to produce. Six per *control frame*." | unchanged; add "(I-11). It is limited to the *authority box* by the *control allocation* (L2-AER-FC-170)." |
| Reference position | "The horizontal position over the ground that autoflight holds while *Stationary* or *Hover* is active. Whether it is the position at engagement or where the vehicle stops is set at L2 (#78)." | Add: "It is the reference value of the north and east *axis references* while the horizontal axes regulate position; *autoflight* sends it as an absolute position, and *flight control* latches nothing at an engagement." Reason: names the flight control side; #78 stays with C5. |
| Control law | "The rule by which the flight-control function turns references and vehicle state into *effector* commands. Defined at L2 (D33)." | unchanged; add "Its structure and gains are design decisions (DD-300, -07), not requirements (D4)." |
| Gear state | (as defined) | Add "It is also given to *flight control*, which uses it only for the descent call of L2-AER-FC-210 (CR-C4-02)." |
